# CCNA-Enterprise-Network-Lab

## Overview

This project is a simulated enterprise network lab designed to demonstrate practical Cisco networking and troubleshooting skills.

The lab focuses on configuring network devices, creating VLANs, establishing connectivity, and troubleshooting common enterprise network issues.

## Project Purpose

The purpose of this project is to demonstrate hands-on networking knowledge through simulated enterprise network environments.

The lab is designed to reinforce CCNA-level concepts while documenting the configuration and troubleshooting process.

## Skills Demonstrated

- Cisco IOS configuration
- VLAN configuration
- Trunking
- Inter-VLN routing
- IP addressing
- Subnetting
- DHCP
- DNS
- Static routing
- Dynamic routing concepts
- Network connectivity testing
- Network troubleshooting
- Network documentation
- Packet Tracer lab development

## Lab Environment

The lab uses simulated Cisco networking environments to practice enterprise network configuration and troubleshooting. 

Network topologies and configurations are documented within the repository.

## Labs

The `labs` folder contains individual networking scenarios and exercises.

Each lab focuses on a specific networking concept or troubleshooting situation.

## Configurations

The `configs` folder contains documented Cisco device configurations used throughout the labs.

## Packet Tracer

The `packet-tracer` folder contains Cisco Packet Tracer lab files and related resources.

## Documentation

The `documentation` folder contains explanations, configuration guides, troubleshooting procedures, and network documentation.

## Scripts

The `scripts` folder contains supporting scripts used for network-related tasks where applicable.

## Topology

The `topology` folder contains network diagrams and topology documentation.
